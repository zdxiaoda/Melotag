音签 Melotag 1.2.1
==================

跨平台音乐标签编辑器。

启动方式
--------
从开始菜单或桌面快捷方式启动 Melotag。
本安装包已包含 .NET 运行时，无需另外安装。

数据目录
--------
%APPDATA%\Melotag
可用环境变量 MELOTAG_DATA_DIR 覆盖。

卸载
----
设置 → 应用 → 已安装的应用 → 音签 Melotag → 卸载。
