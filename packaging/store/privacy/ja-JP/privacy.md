# Melotag プライバシーポリシー

発効日：2026-11-03

本ポリシーは、Windows デスクトップ版 Melotag（以下「Melotag」）における情報の取り扱いを説明します。Melotag はローカル音楽タグ編集ツールであり、アカウント登録は不要です。広告、アクセス解析、テレメトリーの仕組みも組み込んでいません。

## ローカルファイル

Melotag は、ユーザーが追加または選択した音楽ファイル、歌詞、カバー画像だけを読み込み、保存、名前変更、書き出しなどの操作を実行したときに該当ファイルへ書き込みます。音声ファイルの内容、埋め込みカバー、歌詞全文をアップロードすることはなく、ファイルのフルパスをサーバーへ送信することもありません。オンライン検索では、検索に必要な曲名、アーティスト名、アルバム名、ファイル名（パスを含みません）などのテキストと、選択したサービスが返す識別子を送信します。通常のネットワークリクエストと同様、IP アドレスや User-Agent などの技術情報も含まれます。ローカルファイル自体は送信しません。

## 端末内に保存されるデータ

設定は `%APPDATA%\Melotag\settings.json`、履歴は同じフォルダーの `history.db`（SQLite）に保存されます。保存される内容は次のとおりです。

- 最近使用したフォルダーと管理対象フォルダー
- 履歴内のドライブに対する相対パス（絶対パスそのものは保存しません）、ファイルサイズ、更新日時
- 保存または名前変更前のタグと歌詞のスナップショット
- オンラインソースの順序、言語、テーマ、歌詞・カバーに関する設定
- Last.fm API キーを入力した場合、そのキーは `settings.json` に平文で保存されます。Last.fm ソースを使用すると、キーはリクエストとともに Last.fm へ送信されます

これらのファイルは既定では端末内にのみ存在します。`settings.json` や `history.db` を信頼できない相手と共有しないでください。`MELOTAG_DATA_DIR` で保存先を変更した場合は、設定と履歴はそのフォルダーに保存されます。

## オンライン検索

オンラインタグマッチ、カバー検索、歌詞検索をユーザーが実行したときに、Melotag はこれらの機能のためにネットワークへ接続します。オンライン検索では、検索テキスト（通常は曲名、アーティスト名、アルバム名）を選択した第三者サービスへ送信します。対象には、中国の音楽サービス（NetEase Cloud Music、QQ Music、Kugou、Kuwo）および国際的なサービス（MusicBrainz、Cover Art Archive、iTunes Search API、Last.fm、LRCLIB）が含まれます。リクエストは各サービスのドメインへ直接送信され、そのプライバシーポリシーと稼働状況の影響を受けます。Melotag は返却内容を管理できず、結果の網羅性や常時の可用性を保証しません。

起動時、Melotag は既定で GitHub Releases に最新バージョンを問い合わせます。このリクエストには通常のネットワーク情報（IP アドレス、User-Agent など）が含まれます。起動時の確認は設定でオフにでき、ヘルプメニューから手動で確認することもできます。

## アカウント、広告、統計

Melotag はアカウント機能を提供せず、広告を表示せず、第三者の解析、クラッシュレポート、行動追跡 SDK を組み込んでいません。個人情報を販売、貸与、共有することはありません。オンライン検索は第三者サービスへ直接接続するため、各サービスが独自のポリシーに基づいてリクエストを記録する場合があります。

## ユーザーによる管理

- 「履歴」パネルから履歴を消去できます。
- `%APPDATA%\Melotag` フォルダーを削除すると、設定、履歴、ローカルデータベースを削除できます。削除前にアプリを終了してください。
- アプリをアンインストールしても、編集した音楽ファイルは削除されません。リストからファイルを外しても、ディスク上のファイルは削除されません。
- オンラインサービス側のデータについては、各サービス提供者へ直接お問い合わせください。

## ポリシーの更新と連絡先

本ポリシーは機能の変更に応じて更新される場合があります。更新版には新しい発効日を記載します。プライバシーに関するご質問は、https://github.com/zdxiaoda/Melotag/issues までお寄せください。
