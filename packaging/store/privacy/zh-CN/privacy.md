# 音签 Melotag 隐私政策

生效日期：2026-11-03

本政策说明音签 Melotag（以下简称“Melotag”）在 Windows 桌面版中如何处理信息。Melotag 是一款本地音乐标签编辑工具，不要求注册账号，也不包含广告、分析或遥测组件。

## 本地文件

Melotag 只读取你主动添加或选择的音乐文件、歌词与封面图片，并在你执行保存、重命名或导出操作时写入相应文件。应用不会上传音频文件内容、内嵌封面或歌词全文，也不会把文件的完整路径发送到任何服务器。在线查询会发送完成搜索所需的曲名、艺术家、专辑或文件名（不含路径）等文本，以及所选服务返回的标识；与所有网络请求一样，请求也会包含 IP 地址、User-Agent 等常规技术信息。不会附带本地文件本身。

## 本地保存的数据

设置保存在 `%APPDATA%\Melotag\settings.json`，历史记录保存在同目录的 `history.db`（SQLite）。这些数据可能包括：

- 最近使用的目录和已管理目录；
- 历史记录中相对于所在卷的路径（不保存完整绝对路径）、文件大小与修改时间；
- 保存或重命名前的标签与歌词快照；
- 在线源顺序、语言、主题、歌词与封面选项等偏好；
- 如果你填写了 Last.fm API key，该密钥会以明文形式保存在 `settings.json` 中；使用 Last.fm 源时，它会随请求发送给 Last.fm。

上述文件默认只存放在本机。请不要把 `settings.json` 或 `history.db` 分享给不受信任的人。如果通过 `MELOTAG_DATA_DIR` 指定了其他数据目录，设置与历史会保存在该目录。

## 在线查询

只有在你主动使用在线标签匹配、封面搜索或歌词搜索时，Melotag 才会为这些功能发起网络请求。在线查询会把搜索文本（通常是曲名、艺术家、专辑）发送给所选第三方服务，可能包括国内音乐平台（网易云音乐、QQ 音乐、酷狗、酷我）以及国际服务（MusicBrainz、Cover Art Archive、iTunes Search API、Last.fm、LRCLIB）。请求会直接发往这些服务的域名，并受其隐私政策和可用性约束。Melotag 不控制这些服务的返回内容，也无法保证结果完整或始终可用。

启动时，Melotag 默认向 GitHub Releases 查询最新版本；该请求包含常规网络元数据（如 IP 地址、User-Agent）。你可以在设置中关闭启动检查，仍可通过帮助菜单手动检查。

## 账号、广告与统计

Melotag 不提供账号系统，不展示广告，也不集成第三方分析、崩溃上报或行为追踪 SDK。我们不会出售、出租或共享你的个人信息。由于在线查询直接连接第三方服务，相关服务仍可能按其自身政策记录请求。

## 你的控制权

- 在“历史”面板中清空历史记录。
- 删除 `%APPDATA%\Melotag` 目录以移除设置、历史与本地数据库；删除前请先退出应用。
- 卸载应用不会自动删除你编辑过的音乐文件；从列表移除文件也不会删除磁盘上的文件。
- 如需了解或删除与在线服务相关的数据，请直接联系相应服务提供方。

## 政策更新与联系

本政策可能随功能变化而更新，更新后的版本会标注新的生效日期。如有隐私相关问题，请通过 https://github.com/zdxiaoda/Melotag/issues 联系我们。
