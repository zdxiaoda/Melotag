## 短いタイトル

Melotag

## 短い説明（270 文字以内）

ダウンロードした音楽を一か所で整理。タグ編集、カバー画像、歌詞検索、ファイル名の一括変更に対応します。MP3、FLAC、M4A などの形式に対応し、編集と保存は端末内で完結。オンライン検索は必要なときだけ。無料・アカウント不要・広告なし。UI は日本語・簡体中文・English。

## 詳細説明

音楽ライブラリに、こんな曲はありませんか。曲名が文字化けしている、アルバムアートが空っぽ、プレイヤーでは「不明なアーティスト」、歌詞はどうしても合わない。Melotag は、そうしたタグの散らかりを片付けるためのアプリです。

ファイルやフォルダーをウィンドウにドラッグすると、左に曲リスト、右にタグ編集画面が並びます。タイトル、アーティスト、アルバム、アルバムアーティスト、年、トラック、ディスク、ジャンル、コメント、作曲者、歌詞、カバー画像を編集でき、MP3 では ID3 のバージョン選択やファイルの更新日時の保持も可能です。保存すると、別のデータベースではなく音声ファイルそのものに書き戻します。ストア版には Windows x64 と arm64 が含まれ、Linux 版と Android 版はプロジェクトの Release から入手できます。

1 曲ずつ入力するのが面倒なときは、オンライン検索に任せられます。複数の音楽データベースを同時に検索し、タグ、カバー、歌詞の候補を並べて選べます。取り込む項目、使うデータベース、上書きするかどうかを先に決めてから、まとめて処理することもできます。歌詞は検索、タイムタグの整理、余分なタグや空行の削除、全体のオフセット調整、UTF-8／GB18030／Big5 などでの読み込みと書き出しに対応します。

ファイル名も一緒に整えられます。「アーティスト - タイトル」のようなテンプレートや正規表現で新しい名前をその場でプレビューし、重複する名前には自動で番号を付けます。同名の .lrc とカバー画像も一緒に変更できます。簡体字・繁体字の変換はタグとファイル名の両方に対応し、変更前に結果を確認できます。

いちばん大事なのは、あなたの音楽を外に出さないこと。音声ファイルをアップロードすることはなく、アカウント登録も広告も、聴いた内容を裏で記録することもありません。オンライン検索を選んだとき、または更新を確認したときにだけ通信します。設定と履歴は端末内に保存され、保存や名前変更の前にはタグのスナップショットを自動で残すので、間違えても後から戻せます。

いくつか注意点があります。DSF/DFF は認識できますが、実際の DSD ファイルでの書き込み検証は十分ではありません。複数の音声トラックを含むファイルは処理対象外です。オンラインの結果は第三者サービスに依存するため、不足したり一時的に使えなかったりすることがあります。一括変更の前には元ファイルのバックアップをおすすめします。

UI は日本語、簡体中文、English に対応し、初回はシステム言語に合わせて表示されます。設定からいつでも切り替えられます。

## 製品の機能（10 項目）

1. タグ編集：タイトル、アーティスト、アルバム、アルバムアーティスト、年、トラック、ディスク、ジャンル、コメント、作曲者、歌詞、カバー画像。MP3 の ID3v2.3/2.4 選択や更新日時の保持にも対応。
2. 対応形式：MP3、FLAC、APE、OGG、M4A、WAV、WMA、DSF、DFF など。再生時間、ビットレート、サンプルレート、チャンネル、ファイルサイズも表示。
3. オンラインマッチ：複数の音楽データベースを同時に検索し、タグ、カバー、歌詞の候補を比較。1 曲ずつ適用するか、項目と上書き方法を決めて一括処理。
4. 歌詞ツール：LRC の検索、タイムタグの整理、余分なタグや空行の削除、オフセット調整、一般的な文字コードでの読み込みと書き出し。
5. カバー画像：オンライン検索またはローカル画像を選択し、適切なサイズに自動縮小して保存時に書き戻し。書き出し、削除、一括抽出も可能。
6. テンプレート／正規表現リネーム：新しいファイル名をその場でプレビューし、重複時は自動採番。同名の .lrc とカバーも一緒に変更。
7. ファイル名からタグへ：ファイル名や正規表現から情報を取り出し、タグに書き戻して命名のばらついたライブラリを整理。
8. 簡体字・繁体字変換：タグとファイル名を双方向に変換。同名の歌詞とカバーもまとめて処理。
9. 履歴と復元：変更前にタグのスナップショットを自動保存。履歴パネルから確認、復元、削除が可能。
10. 3 プラットフォーム・3 言語：Windows、Linux、Android で同じ操作感。UI は日本語・簡体中文・English。無料、アカウント不要、広告なし。

## スクリーンショットのキャプション

- 01-main：メイン画面：ファイル一覧とタグ編集を並べて表示。ファイルやフォルダーをドラッグして追加し、状態や形式、音声情報を確認できます。
- 02-lyrics：歌詞パネル：LRC 歌詞を検索し、タイムタグを整理してプレビュー。歌詞ファイルの読み込みと書き出しも行えます。
- 03-rename：リネーム：テンプレートまたは正規表現で新しいファイル名を生成。重複処理をプレビューし、歌詞とカバーの同時変更も選べます。
- 04-settings：設定：検索、オンラインソース、歌詞、カバー、書き込み、UI のカテゴリ別に整理。言語、テーマ、起動時の更新確認を変更できます。

## 追加のシステム要件

1. Windows 10 バージョン 2004（ビルド 19041）以降、x64 または arm64 プロセッサ。
2. Microsoft Store 版には実行に必要なコンポーネントが含まれているため、.NET ランタイムを別途インストールする必要はありません。
3. オンラインのタグ・カバー・歌詞検索にはネットワーク接続が必要です。ローカルでの編集と保存はオフラインでも行えます。
