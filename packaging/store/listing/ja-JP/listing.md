## 短い説明（270 文字以内）

クロスプラットフォームの音楽タグエディター。Windows・Linux 版と Android 版は .NET 10 と Avalonia 12 のタグコアと UI コードを共有します。タグやカバー画像の編集、LRC 歌詞の検索と調整、テンプレート／正規表現によるファイル名変更、複数ソースのオンラインマッチ、簡体字・繁体字変換、ローカル履歴からの復元に対応。ストアでは Windows x64 版を提供し、他のプラットフォームはプロジェクトの Release から入手できます。UI は日本語・簡体中文・English。

## 詳細説明

Melotag は、Windows、Linux、Android に対応するローカル音楽タグエディターです。ダウンロードした楽曲の情報を整えたり、アルバム情報やカバー画像、歌詞をまとめて管理したりするときに役立ちます。ファイルやフォルダーをウィンドウにドラッグするだけで、タイトル、アーティスト、アルバム、アルバムアーティスト、年、トラック、ディスク、ジャンル、コメント、作曲者、歌詞、カバー画像を 1 曲ずつ編集できます。形式、再生時間、ビットレート、サンプルレート、チャンネル、ファイルサイズなどの音声情報も確認できます。保存時には MP3 の ID3v2.3/2.4 を選べ、ファイルの更新日時を保持するか、歌詞をタグに書き込むか、カバー画像を置き換えるか削除するかを指定できます。

Melotag は .NET 10、C#、Avalonia 12 で構築されています。Windows、Linux、Android 版は同じタグ処理コアと UI コードを共有し、ファイル一覧、編集手順、設定項目が各プラットフォームでそろいます。Electron や Chromium のシェルは使わず、画面は Avalonia が描画し、処理は同じ .NET プロセス内で動きます。タグの読み書きは TagLib# によりローカルで完結し、一括マッチ、名前変更、保存の際に音声ファイルをアップロードしないため、複数曲をまとめて整理するときもアップロードを待つ必要はありません。オンラインマッチは必要なときにメタデータ、カバー、歌詞を問い合わせます。Microsoft Store では Windows x64 版を提供し、Linux 版と Android 版はプロジェクトの Release から入手できます。

オンラインマッチでは複数の音楽データベースを同時に検索でき、候補のタグ、カバー画像、歌詞を 1 か所で比較できます。1 曲ずつ結果を選んで適用するほか、一括自動マッチでは取り込むフィールド、使用するオンラインソース、上書き方法を先に指定してからファイルごとに処理できます。歌詞パネルでは LRC 歌詞の検索、複数タイムスタンプの整理、タイムタグの削除、空行と先頭タグの削除、オフセット調整、UTF-8／UTF-16／GB18030／Big5 などの文字コードによる読み込みと書き出しに対応します。カバー画像はオンライン検索またはローカルファイルから選択でき、容量、幅、高さ、形式の上限に合わせて自動的に縮小されます。

ファイル名の変更には @0～@8 のフィールドテンプレート、既定の「アーティスト - タイトル」、正規表現のキャプチャグループを使えます。新しいファイル名をプレビューでき、名前が重複する場合は自動で番号が付きます。同名の .lrc とカバー画像を一緒に変更することもでき、ファイル名からタグを書き戻す逆方向モードも利用できます。簡体字・繁体字の変換はタグとファイル名の両方に対応し、同名の .lrc とカバー画像も処理します。保存や名前変更のたびに、変更前のタグのスナップショットがローカルの履歴データベースに保存され、履歴パネルから確認、復元、削除ができます。

UI は日本語、簡体中文、English に対応し、初回はシステム言語に合わせて表示されます。設定画面では表示言語をすぐに切り替えられるほか、ダーク／ライトテーマ、コンパクトな行表示、オンラインソースの順序、検索地域などを変更できます。起動時の更新確認は既定で有効ですが、設定からオフにできます。ヘルプメニューから手動で確認することも可能です。

ご注意：DSF/DFF は認識できますが、実際の DSD サンプルを使った書き込み検証は十分ではありません。複数の音声トラックを含むファイルは処理対象から除外されます。オンラインマッチ、カバー画像、歌詞の結果は、選択した第三者サービスの稼働状況と返却内容に依存するため、情報が不足する場合や一時的に利用できない場合があります。一括変更の前に元ファイルのバックアップを取ることをおすすめします。

## 製品の機能（10 項目）

1. タグ編集：タイトル、アーティスト、アルバム、アルバムアーティスト、年、トラック、ディスク、ジャンル、コメント、作曲者、歌詞、カバー画像に対応。MP3 の ID3v2.3/2.4 選択や更新日時の保持も可能です。
2. 音声情報と対応形式：MP3、FLAC、APE、WavPack、TTA、MPC、OGG、Opus、M4A、MP4、WAV、AIFF、WMA、DSF、DFF を認識し、再生時間、ビットレート、サンプルレート、チャンネル、ファイルサイズを表示します。
3. 複数ソースのオンラインマッチ：複数の音楽データベースを同時に検索でき、タグ、カバー、歌詞の候補を比較。1 曲ずつ適用するほか、フィールド、ソース、上書き方法を指定した一括自動マッチも使えます。
4. LRC 歌詞ツール：歌詞検索、複数タイムスタンプの整理、タイムタグや空行・先頭タグの削除、オフセット調整、UTF-8／UTF-16／GB18030／Big5 などでの読み込みと書き出しに対応します。
5. カバー画像管理：オンライン検索、ローカル画像の選択、書き出し、削除、一括抽出に対応。容量、幅、高さ、形式の上限に合わせて自動縮小します。
6. テンプレートと正規表現のリネーム：@0～@8 のフィールド、既定の「アーティスト - タイトル」、正規表現のキャプチャグループを使い、プレビューと重複時の自動採番を提供。同名の .lrc とカバーも一緒に変更できます。
7. ファイル名からタグへ：ファイル名や正規表現から抽出した情報をタグに書き戻し、出所の異なる楽曲の整理に役立ちます。
8. 簡体字・繁体字変換：タグとファイル名の両方を簡体字から繁体字、繁体字から簡体字へ変換し、同名の .lrc とカバーも処理します。
9. 履歴と復元：保存や名前変更の前にタグのスナップショットをローカルデータベースへ記録。履歴パネルから確認、復元、削除ができます。
10. クロスプラットフォームと三言語 UI：Windows、Linux、Android が .NET 10 と Avalonia 12 のタグコアと UI コードを共有し、操作も共通です。ストアは Windows x64 版を提供し、他のプラットフォームはプロジェクトの Release から入手できます。三言語 UI、設定と履歴はローカル保存。

## スクリーンショットのキャプション

- 01-main：メイン画面：ファイル一覧とタグ編集を並べて表示。ファイルやフォルダーをドラッグして追加し、状態や形式、音声情報を確認できます。
- 02-lyrics：歌詞パネル：LRC 歌詞を検索し、タイムタグを整理してプレビュー。歌詞ファイルの読み込みと書き出しも行えます。
- 03-rename：リネーム：テンプレートまたは正規表現で新しいファイル名を生成。重複処理をプレビューし、歌詞とカバーの同時変更も選べます。
- 04-settings：設定：検索、オンラインソース、歌詞、カバー、書き込み、UI のカテゴリ別に整理。言語、テーマ、起動時の更新確認を変更できます。
