音签 Melotag

## 简短标题

音签 Melotag

## 简短说明（不超过 270 字符）

跨平台音乐标签编辑器，其 Windows、Linux 与 Android 版共享 .NET 10 与 Avalonia 12 的标签核心和界面代码。批量整理音乐库，编辑标签与封面、搜索并处理 LRC 歌词、按模板或正则重命名文件，支持多源在线匹配、简繁转换和本地历史恢复。商店提供 Windows x64 / arm64 包，其他平台见项目 Release。

## 详细说明

音签 Melotag 是一款本地音乐标签编辑器，适合整理下载的音乐、补全专辑信息，以及为本地曲库统一封面与歌词。把文件或文件夹拖入窗口后，可以逐首编辑标题、艺术家、专辑、专辑艺术家、年份、音轨、碟号、流派、注释、作曲、歌词与封面，并查看格式、时长、码率、采样率、声道和文件大小等音频信息。保存时可为 MP3 选择 ID3v2.3/2.4、保留文件修改时间，并决定是否把歌词写入标签、替换或清除封面。

音签 Melotag 使用 .NET 10、C# 与 Avalonia 12 构建。Windows、Linux 和 Android 版本共享同一套标签处理核心与界面代码，文件列表、编辑流程和设置项在各端保持一致。应用不使用 Electron 或 Chromium 外壳，界面由 Avalonia 绘制，逻辑运行在同一个 .NET 进程中。标签读写通过 TagLib# 在本地完成，批量匹配、重命名和保存都不上传音频文件，整理多首曲目时不必等待上传；在线匹配只在需要时查询元数据、封面或歌词。商店提供 Windows x64 / arm64 包，Linux 与 Android 版本可从项目 Release 获取。

在线匹配可同时查询多个音乐数据源，把候选标签、封面与歌词放在同一处比较；单曲可选择结果后应用，批量自动匹配则可先指定要导入的字段、参与的在线源和覆盖方式，再逐文件处理。歌词面板支持搜索 LRC 歌词、整理多时间戳、移除时间标签、删除空行与头部标签、整体偏移，以及按 UTF-8、UTF-16、GB18030、Big5 等编码导入和导出。封面工具可在线查找或从本地选择图片，并按体积、宽高和格式限制自动缩放。

重命名支持 @0–@8 字段模板、默认“歌手 - 歌名”规则和正则捕获组，提供实时预览与重名自动编号，也能连带处理同名 .lrc 与封面文件；反向模式可根据文件名写回标签。简繁转换覆盖标签与文件名，并可同步处理同名 .lrc 与封面。历史面板则把每次保存或重命名前的标签快照存入本地数据库，可随时查看、恢复或清空。

界面提供简体中文、日本語和 English，默认跟随系统并可即时切换；深色/浅色主题、紧凑行高、在线源排序和搜索地区等选项都在设置中。启动时会静默检查新版本，也可在帮助菜单手动检查，并可在设置中关闭。

说明：DSF/DFF 文件可以识别，但写入尚未用真实 DSD 样本充分验证；包含多音轨的音频文件会被跳过。在线匹配、封面和歌词结果取决于所选第三方服务的可用性与返回内容，可能不完整或暂时不可用。建议在批量修改前保留原始文件备份。

## 产品功能（10 条）

1. 逐首标签编辑：标题、艺术家、专辑、专辑艺术家、年份、音轨、碟号、流派、注释、作曲、歌词与封面；MP3 可选 ID3v2.3/2.4 并保留文件修改时间。
2. 音频信息与格式：识别 MP3、FLAC、APE、WavPack、TTA、MPC、OGG、Opus、M4A、MP4、WAV、AIFF、WMA、DSF 与 DFF，显示时长、码率、采样率、声道和大小。
3. 多源在线匹配：同时查询多个音乐数据库，比较标签、封面与歌词候选；支持单曲应用，以及先选字段、在线源和覆盖方式的批量自动匹配。
4. LRC 歌词工具：搜索歌词，整理多时间戳，移除时间标签、空行和头部标签，整体偏移，并按 UTF-8、UTF-16、GB18030、Big5 等编码导入导出。
5. 封面管理：在线查找、本地选择、导出、移除与批量提取；按体积、宽高和格式上限自动等比缩放，保存时写回标签。
6. 模板与正则重命名：使用 @0–@8 字段、默认“歌手 - 歌名”或正则捕获组，实时预览并按重名自动编号；可连带重命名 .lrc 与封面。
7. 文件名写回标签：反向模式下从文件名或正则表达式提取信息并写入标签，适合整理命名规则不一的曲库。
8. 简繁转换：标签与文件名支持简转繁、繁转简，并可同步处理同名 .lrc 与封面文件。
9. 历史与恢复：每次保存或重命名前把标签快照写入本地数据库，可在历史面板查看、恢复选中版本或清空记录。
10. 跨平台与三语界面：Windows、Linux 与 Android 共用 .NET 10 + Avalonia 12 的标签核心与界面代码，操作方式一致；商店提供 Windows x64 / arm64 包，其他平台见项目 Release。界面支持简中、日本語与 English，设置与历史保存在本机。

1. Windows 10 版本 2004（内部版本 19041）或更高版本；x64 或 arm64 处理器。
