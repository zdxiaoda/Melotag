# 认证备注草稿（Notes for certification）

适用版本：应用 `1.2.1`；MSIX 包版本 `1.2.1.0`。

> 本文是提交给 Microsoft Store 认证团队的备注草稿及中文说明，不代表应用已经提交、通过认证、上架或获得任何评级。英文正文中的版本号、包标识和隐私政策 URL 在提交前必须按最终 MSIX 和实际公开地址核对。

## 1. 英文草稿

复制下面代码块中的正文到 Partner Center 的 Notes for certification 字段。不要加入无法验证的测试账号、密码或授权信息。

```text
Melotag 1.2.1 - notes for certification

Melotag is a full-trust Windows desktop tag editor for local audio files, packaged as MSIX (Windows.FullTrustApplication). Full trust is used to read and write user-selected audio, .lrc, and cover files, preserve timestamps, and rename files in place. It does not install a service or driver and does not require administrator rights.

No account or test credentials are required. Launch from Start, add files/folders by drag-and-drop, File > Add Files…, or Open With, and use copies of your own MP3/FLAC files. Edit tags and save; changes are written to the selected files. Core editing, lyric/cover tools, rename, and local history work offline. Online tag, cover, and lyric lookups are optional and require internet plus third-party services.

No music, lyrics, or cover art is bundled. Screenshots use a fictional demo library with synthetic metadata, lyrics, and cover art generated by our capture script. Online lookups query public third-party services; Melotag is not affiliated with or endorsed by them, and results may be incomplete or unavailable. An optional user-supplied Last.fm API key can be entered for the Last.fm source; it is not a Melotag account.

Privacy: settings and history stay in %APPDATA%\Melotag (or MELOTAG_DATA_DIR). Online searches send search text (title, artist, album, or filename without the path) and standard request data (IP, User-Agent) to the selected service. Audio content, embedded covers, full lyrics, and full paths are not uploaded. No ads, analytics, or telemetry. The startup update check only queries GitHub Releases and shows a link; it does not download or install updates. The privacy policy is provided via the URL in Partner Center; repository source for review: https://github.com/zdxiaoda/Melotag/blob/main/packaging/store/privacy/en-US/privacy.md

Known limitations: DSF/DFF files are recognized, but writing has not been validated with real DSD samples. Files containing multiple audio tracks are skipped. The package registers .mp4 for tag editing; the app is not a media player and does not play audio/video.

Support: https://github.com/zdxiaoda/Melotag/issues
```

## 2. 中文说明

### 2.1 用途

- 这是 Partner Center “Notes for certification” 字段的英文草稿，不是商店 listing 正文，也不是认证结论。
- 英文正文保持简洁，重点回答审核员最关心的问题：应用类型、为什么需要 full trust、如何测试、是否需要账号、是否内置内容、在线功能依赖什么、数据如何处理、有哪些已知限制。
- 不要加入虚构的测试账号、密码、年龄验证信息或“已获批准”之类的表述；本应用不需要账号即可完成核心测试。

### 2.2 草稿覆盖的事实

| 事实 | 草稿中的对应说明 | 中文补充 |
| --- | --- | --- |
| full trust | `full-trust Windows desktop tag editor`、`Windows.FullTrustApplication` | 需要读写用户选择的音频、`.lrc` 和封面文件，保留时间戳并原地重命名；不安装服务或驱动，不需要管理员权限 |
| 无需账号 | `No account or test credentials are required` | 启动后可直接添加文件、编辑、保存；不要在认证备注里编造测试账号 |

### 2.3 提交前核对

1. 版本号和包标识：确认草稿中的 `1.2.1` 与最终 MSIX 的 `Identity Version 1.2.1.0`、Partner Center 产品标识一致。
2. 隐私政策 URL：草稿保留了 `main` 分支上的英文隐私政策源文件路径，并注明公开 URL 以 Partner Center 字段为准。该源文件只有在推送到公开仓库后才可访问；提交前用无痕窗口验证。如果尚未公开，请以 Partner Center 中实际填写的公开 URL 为准，不要把 404 链接交给审核员。
3. 在线服务名单：草稿没有逐项列出第三方服务，但隐私政策和 listing 应保留实际使用的服务类别。如果发布前移除或新增了某个源，同步修改隐私政策和认证备注。
4. `.mp4` 关联：包清单把 `.mp4` 列为支持的文件类型。草稿明确说明应用是标签编辑器、不是播放器；如果发布前调整了关联范围，同步修改草稿。
5. 多音轨说明：当前 listing 和项目文档把多音轨文件描述为跳过。提交前用最终 MSIX 复核实际行为；如果构建的实际行为与“跳过”不一致，应先修正 listing/本文，而不是在认证备注中保留无法验证的说法。
6. 截图素材：截图中的曲名、艺术家、歌词和封面是截图脚本在 `%TEMP%` 生成的虚构演示数据，不是用户库或版权内容。草稿已说明这一点。
7. 支持和网站：支持 URL 使用 `https://github.com/zdxiaoda/Melotag/issues`；网站使用 `https://github.com/zdxiaoda/Melotag`。提交前确认可访问。
8. 认证备注字段可能有长度限制；如果页面提示超限，先按 2.4 节裁剪，不要删除 full trust、无需账号、离线核心、无内置内容、第三方依赖和格式限制这些关键事实。

### 2.4 字符数超限时的裁剪顺序

上面的英文正文约 1,900 字符。如果页面提示超限，可优先删除：

1. 在线服务名单的重复描述；
2. 支持 URL 或隐私政策段落中与 Partner Center 字段重复的内容；
3. `Open With`、拖放等操作细节中的一项，但保留至少一种启动/添加文件方式；
4. 非关键的格式限制说明，但不要删除 DSF/DFF 和多音轨限制。

无论怎样裁剪，都应保留以下核心事实：

- full trust 桌面标签编辑器，只处理用户选择的文件；
- 无需账号/测试凭据；
- 核心功能可离线测试；
- 无内置音乐/歌词/封面，截图素材为虚构；
- 在线结果来自第三方，无隶属或背书；
- 数据本地保存，在线查询只发送搜索文本和常规请求信息；
- DSF/DFF 写入限制和多音轨限制。

### 2.5 不要写的内容

- 不要写“应用已通过认证”“已获得某年龄评级”或“已上架”。
- 不要写无法验证的测试账号、密码、API key 或内部链接。
- 不要声称“没有任何网络请求”“不处理任何用户内容”或“所有第三方内容都经过审核”；这些与代码和隐私政策不一致。
- 不要声称应用内置了演示音乐、歌词或封面；截图中的素材是临时生成的虚构内容，不在发布包内。
- 不要把本文件的中文说明部分粘贴到英文备注字段。
